## 🎯 发布平台差异

### 知乎（Zhihu）

**发布步骤：**
1. 访问 https://zhuanlan.zhihu.com/write
2. 复制文章内容
3. 调整图片（知乎上传图片限制）
4. 添加话题标签：
   - `#Rust语言`
   - `#嵌入式开发`
   - `#汽车电子`
   - `#开源项目`
   - `#工具推荐`

**标题建议（知乎风格）：**
- 用 Rust 重写汽车总线分析工具，性能提升 10 倍！
- 我为什么用 Rust 重写 CAN 分析工具？
- 开源一个高性能 CAN/LIN 总线分析工具
- 告别性能焦虑：Rust 版本的 BLF 解析器有多快？

**优化建议：**
- 添加"创建时间"显示专业性
- 在文末添加"相关文章推荐"
- 回复评论区的问题

### 掘金（Juejin）

**发布步骤：**
1. 访问 https://juejin.cn/editor
2. 选择"技术文章"分类
3. 复制文章内容
4. 选择分类：
   - 主分类：**后端**
   - 次分类：**Rust**、**开源**
5. 添加标签：`Rust` `嵌入式` `汽车电子` `开源` `工具`

**标题建议（掘金风格）：**
- 【开源】用 Rust 重写汽车总线分析工具，性能提升 10 倍！
- Rust 实战：从零开发高性能 CAN 总线分析工具
- 开源 CANVIEW：一个 Rust 实现的 BLF 解析库

**优化建议：**
- 在文章开头添加"阅读时长"（约 8 分钟）
- 添加目录导航
- 使用掘金的代码高亮功能

**知乎：**
1. 点击编辑器上方"图片"图标
2. 上传本地图片
3. 将 `../assets/xxx` 替换为平台生成的链接

**掘金：**
1. 直接拖拽图片到编辑器
2. 掘金自动上传并生成 Markdown
3. 保持原有位置即可

## 📊 发布时间建议

**最佳发布时间：**
- **工作日**：周二、周三 10:00-11:00 或 15:00-16:00
- **周末**：周六、周日 20:00-21:00
- **避免**：周一早晨（忙碌）、周五下午（准备下班）

**原因：**
- 工作日 10-11 点：上班摸鱼刷手机高峰
- 工作日 15-16 点：下午茶时间
- 周末晚上：开发者学习时间

## 🎨 排版优化建议

### Markdown 增强语法

**知乎支持：**
- ```ruby``` 代码块语法高亮（Rust 用 ruby 模式）
- > 引用块
- - [ ] 任务列表
- **加粗** 和 *斜体*

**掘金支持：**
- ```rust``` 原生 Rust 高亮
- 表格、分割线
- HTML 标签（谨慎使用）

### 段落优化
1. 每段不超过 3 行
2. 重要观点用**加粗**强调
3. 使用分隔线 `---` 划分章节
4. 列表不超过 5 项（超过则分组）
