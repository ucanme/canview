## 快速开始

1. **启动**应用。
2. 在顶部栏点击 **File → Open BLF…**,选择一个 `.blf`(或 `.bin`)文件。
   - 文件大于 1 GB 会弹出确认对话框。
3. 默认进入 **Log** 视图查看解码后的报文。点击状态栏左下角的 **Plot** 切换到波形视图。
4. 第一次进入 Plot 时,如果还没有激活的 DBC/LDF 信号库,会弹出 **Select signal library** 浮层 —— 选一个版本来解码信号。

全新安装且尚未配置任何信号库时:点击顶部栏的 **Library** → **+ New Library**,新建版本,然后添加通道并指向你的 `.dbc`(CAN)或 `.ldf`(LIN)文件。

## 加载 BLF 文件

点击顶部栏的 **File** 下拉菜单,有两个选项:

### Open BLF…

用单个文件替换当前已加载的文件。仅支持 `.blf` / `.bin`。文件 > 1 GB 会弹出确认提示。

### Open Multiple BLF…

向当前会话追加多个文件。每个文件并行加载,然后按统一时间线合并。总大小超过 1 GB 会弹出确认提示。

### 加载过程中

- 状态栏显示进度:`⏳ Loading X/Y files (N failed so far) — M messages`。
- 状态栏右侧出现 **❌ Cancel** 按钮 —— 点击取消尚未加载的文件(已加载的保留)。
- 单文件解析错误不会中断整批 —— 失败的文件在 **Loaded Files** 浮层中以 `❌` 标记并显示错误列表。

### 管理已加载的文件

加载 ≥ 2 个文件,或任一文件有解析错误时,点击状态栏左侧的 **文件段** 打开 **Loaded Files** 浮层:

- 每行显示:状态图标(`✅` 正常 / `❌` 错误)、文件名、报文数、字节数、去重后的错误列表。
- 点击行尾的 **✕** 移除该文件。
- **Remove All**(左下)清空所有文件。
- **Done**(右下)关闭浮层。
- 文件 > 8 个时列表会滚动;≤ 8 个时浮层按内容高度紧凑收缩。

## 日志视图 (Log View)

加载 BLF 后默认进入此视图。每行对应一条 CAN/LIN 报文。

### 列

| 列        | 行为 |
|-----------|------|
| **#**     | 行号。 |
| **TIME**  | BLF 有 start time 时显示绝对时间(`YYYY-MM-DD HH:MM:SS.ffffff`),否则显示相对秒数。 |
| **CH**    | 通道号。点击表头旁边的 ⚙ 打开通道筛选下拉;点击 ✓ 清除筛选。 |
| **TYPE**  | 按类型着色:CAN/CAN2 绿色、CAN_ERR 红色、CAN_FD/CAN_FD64 紫色、CAN_OV 琥珀色、LIN/LIN2 蓝色。 |
| **ID**    | 报文 ID。点击 ID 标签切换十进制 ⇄ 十六进制(后缀小字 `10` / `16` 表示当前进制)。⚙ / ✓ 切换 ID 筛选下拉。 |
| **DLC**   | 数据长度码。 |
| **DATA**  | 原始载荷字节。 |

### 筛选

**ID 筛选**和**通道筛选**操作一致:

1. 点击列表头旁的 ⚙ 打开下拉,列出所有唯一值。
2. 点击某个值直接应用筛选,或输入数字(仅 ID)逐步细化。
3. ✓ 清除筛选。**Escape** 关闭下拉(再按一次清除筛选)。

两个筛选同时启用时按 AND 组合。

### 空状态

显示 *"No messages loaded. Click '📂 Open BLF' to load a file."*

## 波形视图 (Plot View)

通过状态栏左下角的 **Plot** 按钮切换。每个选中信号一行波形。

### 信号侧边栏(左侧,320px)

- 表头显示信号总数。
- **搜索框**按信号名、报文名或 ID 过滤。
- 项按通道(CAN 蓝 / LIN 黄)→ 报文 → 信号三级分组。
- 已配置映射但尚未加载的通道显示 **Load** 按钮 —— 点击加载对应的库版本。
- 每个信号有 12×12 px 复选框,点击加入或移出选择。
- 侧边栏底部的 **Plot N signals (Plot)** 按钮触发数据提取并绘图。

### 工具栏

- **Reset Zoom** —— 仅在已缩放时显示,恢复到完整时间范围。
- **Points: ON/OFF** —— 切换是否在波形上绘制数据点。

### 缩放

- **鼠标滚轮** —— 以光标为中心放大/缩小。最小范围受所有曲线相邻点间距最小值的约束。
- **拖拽框选缩放** —— 在波形上水平拖拽选择区域。选择宽度 > 10 px 时提交缩放,更小的选择被忽略。
- **双击** —— 重置缩放。

### 悬停提示

在波形上移动鼠标会显示:

- 一条垂直的悬停线指向光标 X 位置。
- 一个提示框,显示时间(BLF 有 start time 时为绝对 `YYYY-MM-DD HH:MM:SS.mmm`,否则为相对秒数),以及每条曲线一行:彩色圆点、值、单位。
- 右侧空间不够时提示框自动翻到光标左侧。

### 时间显示

X 轴标签:BLF 有 start time 时显示绝对 `YYYY-MM-DD HH:MM:SS.mmm`,否则显示从首条报文起的相对秒数。

### 单图标题

`{信号名} [{单位}] | {N} pts | {min}s-{max}s (span: {span}s)`

### 空状态

显示 *"尚无数据显示"* / *"请在信号选择(Signals)中选择信号,点击 Plot 按钮加载数据"*,以及一行调试信息(报文数 / 选中数)。

## 信号库管理

通过顶部栏的 **Library** 按钮切换。三栏布局:库 | 版本 | 通道。

### 创建库

1. 在左栏点击 **+ New Library**。
2. 输入名称,**Enter** 提交(或点击 ✓)。**Escape** 取消。

### 添加版本

1. 在左栏选中一个库。
2. 在中栏点击 **+ Add Version**。
3. 输入版本名(如 `v1.0`),按 **Enter**。

### 添加通道(DBC/LDF 文件)

1. 选中库和版本。
2. 在右栏点击 **+ Add Channel**。
3. 按需切换类型(CAN ⇄ LIN)。
4. 输入通道 ID 和通道名(留空时会从文件名自动填充)。
5. 点击 **Select File…** 选择 `.dbc`(CAN)或 `.ldf`(LIN)文件。
6. ✓ 保存,✕ 取消。**Enter** 保存,**Escape** 取消。

数据库文件会被复制到 `<config_dir>/libraries/<库>/<版本>/<通道>/`,原文件可以移动或删除。

### 激活版本

点击版本旁的 ▷ 按钮(激活后变成 ▶)。激活会:

- 把所有已配置通道的 DBC/LDF 数据库加载到内存。
- 更新状态栏右侧的库徽章(`📚 库名 / 版本`)。
- 将激活状态持久化到配置,重启后保留。

点击 ▶ 取消激活。Plot 视图下若无激活版本,会重新出现信号库选择浮层。

### 重命名 / 删除

- **✎** —— 重命名库或版本。内联输入框,✓ / ✕ 确认。
- **🗑** —— 删除库、版本或通道。不可撤销。

### Apply to Plot

点击右栏顶部的 **Apply to Plot** 将当前版本的通道映射写入 app config(不激活)。这会更新 `app_config.mappings` 并保存到磁盘。

## 局域网共享与导入

把你的信号库数据库文件共享给同局域网的其他机器,或导入别人共享的库。

### 启动共享

1. 在 **Library** 视图左下角点击 **📡 Share**。
2. 应用绑定 `0.0.0.0:0`(系统分配端口),暴露:
   - `GET /api/health` —— 无需鉴权的健康检查。
   - `GET /api/libraries?token=...` —— 库列表 JSON,`database_path` 已重写为各通道的下载 URL。
   - `GET /api/libraries/{lib_id}/versions/{ver}/files/{channel_id}?token=...` —— 流式返回 DBC/LDF 文件。
3. 弹出对话框显示 **LAN URL**(优先选 `192.168.x.x` / `10.x.x.x` / `172.16-31.x.x` 地址),以及 `127.0.0.1` 本地回退。
4. **📋 Copy** 复制 URL 到剪贴板。**🌐 Open** 在系统浏览器中打开。
5. 点击 **📡 Stop Share**、关闭应用或 `ServerHandle` 被释放时服务器停止。

token 是一个不透明的随机字符串,每个请求都会校验 —— 分享时务必保留 URL 中的 `?token=...`。

### 在另一台机器导入

1. 在 **Library** 视图点击 **📥 Import**。
2. 将共享 URL(`http://...?token=...`)粘贴到输入框。
3. 点击 **Import**。应用拉取库列表,并把每个通道的数据库文件下载到本地 `libraries/` 子目录。
4. 完成后导入的库出现在你的库管理器中,对话框自动关闭。重名会加 `_1`、`_2` 后缀避免覆盖现有项。

## 配置视图 (Config View)

通过状态栏切换(视图名显示 `config mode`)。主要是只读汇总。

- **Import Database** —— 当前是占位实现,请使用 Library 视图。
- **Save Config** —— 将 `multi_channel_config.json` 写到可执行文件旁。
- **Channel Mappings** —— 只读的当前映射列表(通道 ID、类型、文件路径)。
- **System Status** —— 报文数、DBC 数、LIN 数。

编辑操作在 Library 视图完成,本视图仅用于手动保存和查看状态。

窗口底部 24 px 的栏。

### 左侧

| 段 | 说明 |

| 段 | 说明 |

在文件段可点击时点击触发。详见[加载 BLF 文件](#加载-blf-文件)。

## 键盘快捷键

CANVIEW 没有全局热键注册表,快捷键按视图分别处理。

### 日志视图

| 按键 | 行为 |
|---|---|
| `0`–`9` | 向 ID 筛选文本追加数字(下拉是否打开都生效)。 |
| `Backspace` | 删除 ID 筛选文本末位;文本为空时清除 ID 筛选。 |
| `Enter` | 应用 ID 筛选(把当前文本解析为十进制 u32)。 |
| `Escape` | 关闭 ID 筛选下拉(若打开);否则清除 ID 筛选。 |

### 信号库视图

| 按键 | 上下文 | 行为 |
|---|---|---|
| `Enter` | 新建库输入 | 创建库并关闭输入。 |
| `Enter` | 新建版本输入 | 添加版本并关闭输入。 |
| `Enter` | 新建通道输入 | 保存通道配置。 |
| `Escape` | 任意新增/重命名输入 | 取消且不保存。 |

### 波形视图

- **双击**波形 —— 重置缩放。
- **鼠标滚轮** —— 放大/缩小。
- 无键盘快捷键。

### 窗口控制(Win/Linux)

右上角的最小化 / 最大化 / 关闭按钮仅支持鼠标操作。

## 持久化数据

### 写入磁盘(`multi_channel_config.json`)

位于可执行文件旁(若不可写则回退到当前工作目录)。Pretty JSON 格式。保存时机:

- 创建 / 删除库
- 添加 / 删除版本
- 添加 / 删除通道
- 激活 / 取消激活版本
- Apply to Plot
- Config 视图手动 **Save Config**
- LAN 导入成功后

内容:

- `libraries` —— 完整的库 / 版本 / 通道层级结构。
- `mappings` —— 通道到数据库的映射(类型、ID、文件路径、库 ID、版本名)。
- `active_library_id`、`active_version_name` —— 当前激活的版本。

### 磁盘上的库文件

添加通道时,DBC/LDF 文件被复制到 `<config_dir>/libraries/<库>/<版本>/<通道>/`。macOS 配置目录是 `~/Library/Application Support/canview`,Linux 是 `~/.config/canview`,Windows 是 `%APPDATA%/canview`。

### 仅存于内存(不持久化)

已加载的 BLF 报文、解码后的 DBC/LDF 数据库、波形缩放状态、选中的信号 —— 在窗口最大化/恢复时会保留(通过 `RuntimeState`),但**不会**写入磁盘,应用退出后即丢失。

## 故障排查

### 加载后没有报文

- 检查文件大小 —— > 1 GB 的文件需要确认。
- 打开 Loaded Files 浮层(点击文件段)查看是否有 `❌` 图标 —— 文件可能解析失败。

### 文件名旁出现 ⚠️

文件加载成功但有解析错误。点击该段打开 Loaded Files 浮层,在出错的文件下查看错误列表。

### Plot 视图信号不解码

- 必须是**激活**了一个库版本,而不是仅配置了。检查状态栏右侧的库徽章。
- 若出现 **Select signal library** 浮层,选一个版本,或点 ✕ 关闭。
- 信号侧边栏里未加载的通道旁边点 **Load** 加载对应库版本。

### 服务器 URL 显示 `127.0.0.1` 而非局域网 IP

应用未检测到首选局域网 IP(192.168 / 10. / 172.16-31)。检查是否在一个可路由的局域网内。本地 URL 在同一台机器上仍可用。

### 导入失败

- 确认 URL 包含 `?token=...` 参数。
- 共享端必须在同一局域网可达,且服务器正在运行。
- 查看底部的状态消息获取导入结果。

### 改动重启后丢失

库 / 版本 / 通道改动和激活状态会自动保存。已加载的 BLF 文件和波形状态不会 —— 重启后需要重新加载文件。
